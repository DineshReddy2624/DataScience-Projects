# 📊 LEGO Business Performance Dashboard (Power BI)

## 📌 Problem Statement
Businesses need to analyze product performance, pricing trends, and customer segments to make better decisions. This dashboard provides insights into LEGO set data to understand product distribution, pricing, and category performance.

---

## 📂 Dataset
- 4,385 LEGO sets analyzed :contentReference[oaicite:0]{index=0}  
- Features include:
  - Set name, theme, and category  
  - Age range  
  - Number of pieces  
  - Pricing information  

---

## 🛠 Tools & Technologies
- Power BI  
- DAX (Data Analysis Expressions)  
- Data Modeling
